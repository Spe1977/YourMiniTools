Privacy Policy

Personal Data

YourMiniTools does not collect personal data. No registration, login, or identifying information is required to use the tools.

Cookies

This site does not set its own tracking, analytics, or profiling cookies. Two localStorage keys are used for technical operation:

  • ymt-theme
  • ymt-cookie-seen
  • ymt-lang

Cloudflare hosting infrastructure may set its own technical cookies (e.g. __cf_bm). This cannot be excluded completely.

Data Processing

All main processing happens locally in the browser. Files uploaded by the user (images, text) are not sent to the project's servers.

External Connections

The only connection to external services occurs in the Currency Converter (Tool 12), which queries the Frankfurter API for ECB reference exchange rates. No personal user data is transmitted in this request.

Hosting

The site is hosted on Cloudflare Pages. As part of the hosting infrastructure, Cloudflare may collect anonymized access logs (with anonymized IP).

Analytics

Currently no analytics systems are active. If Cloudflare Web Analytics is activated in the future, it will be a privacy-first service that does not use tracking cookies and is GDPR compliant. This page will be updated accordingly.

Contact

For privacy questions you can contact us through the About page.
