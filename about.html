About

The Project

YourMiniTools is a suite of 12 free micro-tools designed to be fast, simple, and privacy-respecting. Every tool runs directly in the browser, without registration and without sending data to external servers.

Philosophy

We believe online tools should be accessible to everyone, without barriers. That's why YourMiniTools is:

  • Free
  • Privacy-first
  • Fast
  • Accessible
  • Transparent

Technology

The site is built with pure HTML, CSS and JavaScript, no frameworks. It is hosted on Cloudflare Pages for global speed and high expected reliability. The only two external libraries used are qrcode.js for QR generation and jsPDF for PDF export, both hosted locally.

Stated Limitations

  • Compatible with modern browsers (Chrome, Edge, Firefox, Safari from the last 2 years).
  • Variable performance on very old devices or those with limited RAM.
  • Limits on large image files (size and resolution).
  • Exchange rate accuracy depends on the availability of the external provider (Frankfurter API / ECB).
